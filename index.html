Tentang Saya

Saya adalah Quality Assurance Engineer di OLDO Digital yang bertanggung jawab atas penjaminan kualitas produk dan modul digital yang terintegrasi dalam platform MyTelkomsel. CASE STUDY 01 · GAMING

GameHub

Pengalaman mini-game dan fitur gamification dalam aplikasi super app telekomunikasi.

Contoh QA yang telah dianonimkan

Test Overview

Validasi QA untuk mini-games hub dan fitur user engagement/gamification. Ringkasan publik ini berfokus pada test scope dan metodologi pengujian, tanpa menyertakan detail implementasi internal maupun informasi sensitif.

QA Role & Test Approach

Peran Manual QA mencakup feature validation, end-to-end user journey testing, release readiness check, serta re-testing dan regression testing untuk menjamin stabilitas sistem sebelum rilis.

Test Scope

  • Play All Mini Games
  • Checking Inbox
  • Checking Mission
  • Checking Gamelist
  • Checking Daily Check In
  • Checking Reward
  • Checking Leaderboard
  • Checking Profil
  • Checking Stamp Leaderboard
  • Checking Stamp History

Test Scenario

Test Scenario: Melakukan pause pada mini-game, mereset/melanjutkan sesi, lalu memverifikasi konsistensi score, entri leaderboard, dan timer.

Expected Result: Sesi permainan harus mengikuti aturan restart yang ditentukan, di mana timer dan score direset secara konsisten untuk attempt yang baru.

Actual Result: Entri leaderboard dari sesi sebelumnya masih tersimpan (persisted) setelah restart, dan logika timer tidak berjalan sesuai dengan spesifikasi.

Findings Bug

  • Akses Leaderboard: Fitur leaderboard mengalami unhandled error / tidak dapat diakses saat game attempt sedang berlangsung.
  • Konsistensi Score: Terjadi data mismatch di mana pencatatan score pada dua modul game yang berbeda secara tidak terduga menampilkan nilai best score yang sama.
  • Status Sesi: Setelah eksekusi pause dan restart, status leaderboard serta perilaku timer gagal melakukan state reset untuk attempt baru.

Ringkasan temuan kecatatan sistem (defects) yang dianonimkan berdasarkan observasi pengujian. Status perbaikan dan hasil akhir regression test tidak ditampilkan dalam ringkasan ini.

Identifier sensitif, internal link, tangkapan layar privat, serta detail implementasi yang belum dipublikasikan telah dihapus.

CASE STUDY 02 · DIGITAL ENTERTAINMENT

Lifestyle Entertainment

Penelusuran konten dan user journey hiburan dalam berbagai format.

Contoh QA yang telah dianonimkan

Test Overview

Cakupan Manual QA untuk ekosistem konten hiburan (video, audio, games, dan artikel) dengan fokus utama pada validasi aksesibilitas konten, stream stability, dan navigasi UI/UX.

QA Role & Test Approach

Scope mencakup validasi fitur harian, pemeriksaan responsivitas UI dan navigasi, verifikasi akurasi search engine, serta re-testing dan regression testing.

Test Scope

Lifestyle - Video
  • All
  • Series
  • Movie
  • Shorts
  • Live
  • Sport
Lifestyle - Audio
  • Audio
  • Music
Lifestyle - Article
Lifestyle - Comic
Lifestyle - Games

Test Scenario

Test Scenario: Mengakses kategori konten melalui fitur search, lalu memverifikasi kestabilan pencarian serta kesesuaian halaman tujuan dengan kategori yang dipilih pada versi experience aktif.

Expected Result: Kategori yang dipilih mengarahkan pengguna ke halaman yang tepat dan seluruh section konten terdistribusi (render) dengan sempurna.

Actual Result: Hasil pencarian kategori mengarah ke route/experience versi lama (legacy), serta beberapa section konten mengalami penghentian akses (access error).

Findings Bug

  • Search & Navigation: Pencarian kategori entertainment mengarah pada routing/experience versi lama, bukan ke halaman endpoint terbaru.
  • Ketersediaan Konten: Beberapa section konten gagal memuat (failed to load) dan menampilkan access error.
  • Interaksi UI: Terjadi unresponsive UI pada fungsi filter dan tombol copy, serta image asset gagal dimuat ulang (reload) pasca kondisi network reconnection.

Findings telah digeneralisasi dari diskusi QA sebelumnya. Status perbaikan dan hasil final regression tidak dinyatakan di sini.

Detail produk, arsitektur internal, dan isu teknis telah digeneralisasi untuk kebutuhan portofolio publik.
